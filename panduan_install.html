Pasang Kitabah di HP-mu

Panduan singkat supaya aplikasi Kitabah muncul jadi ikon di layar utama HP — tinggal tap, tidak perlu buka browser dan ketik alamat lagi.

💡

Tidak wajib, tapi disarankan. Tanpa dipasang pun aplikasi tetap bisa dibuka lewat browser seperti biasa. Bedanya, kalau dipasang: buka lebih cepat, ada ikon sendiri, dan terasa seperti aplikasi biasa — bukan situs web.

🍎 iPhone
1

Buka link Kitabah di Chrome

Pastikan pakai browser Chrome (bukan aplikasi WhatsApp/Instagram browser bawaan), supaya tombol install-nya muncul.

2

Cari pop-up "Install" atau "Tambahkan ke layar utama"

Biasanya muncul otomatis di bagian bawah layar begitu halaman selesai dimuat. Kalau muncul, langsung tap Install.

3

Tidak muncul otomatis? Pasang manual

Tap ikon titik tiga ⋮ di pojok kanan atas Chrome → pilih "Tambahkan ke Layar Utama" atau "Install app".

4

Tap "Install" atau "Tambahkan"

Muncul konfirmasi nama aplikasi "PPG SIDUTA" — tap sekali lagi untuk menyelesaikan.

5

Selesai — cek layar utama

Pertanyaan Umum
Apakah wajib install?
Tidak. Aplikasi tetap bisa dipakai penuh lewat browser tanpa install. Install cuma bikin lebih cepat dibuka dan terasa seperti aplikasi biasa.
Pop-up install-nya tidak muncul sama sekali, kenapa?
Beberapa kemungkinan: (1) sudah pernah ditutup/diabaikan sebelumnya — coba cara manual lewat menu titik tiga, (2) memori HP penuh, atau (3) versi browser terlalu lama — coba update Chrome/Safari dulu.
Setelah install, apakah perlu login ulang?
Ya, login pertama kali setelah install tetap perlu username & password seperti biasa. Setelah itu sesi login akan tersimpan.
Bagaimana cara uninstall kalau tidak jadi dipakai?
Sama seperti hapus aplikasi biasa — tekan lama ikonnya di layar utama, lalu pilih Hapus/Uninstall. Data di server tidak akan hilang, cuma ikonnya saja yang dihapus dari HP.
